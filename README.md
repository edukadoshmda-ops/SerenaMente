# 🌿 SerenaMente • Playbook, Audiobooks & Superação Emocional

Aplicativo moderno e acolhedor especialmente desenhado para pessoas que estão enfrentando fases difíceis, ansiedade, depressão e sobrecarga emocional.

---

## ✨ Principais Funcionalidades

### 🎧 1. Playbooks & Audiobooks Terapêuticos Interativos
- Guias em áudio baseados em **Terapia Cognitivo-Comportamental (TCC)** e **Mindfulness**.
- Leitor com texto acompanhado em tela e ajuste do tamanho da fonte.
- **Engine de Áudio Integrado (Web Audio API)** com trilha de fundo relaxante gerada proceduralmente:
  - Ondas do Oceano (respiração ritmada)
  - Chuva Suave (pink noise relaxante)
  - Frequência Theta / 432 Hz de Repouso
- **Narração por voz suave** sincronizada com barra de progresso, botão -15s / +15s e controle de velocidade (0.8x, 1.0x, 1.2x).
- **Sleep Timer (Timer de Sono)** para desligar sozinho à noite (5m, 15m, 30m, 45m).
- **Mini-Player Flutuante**: continue ouvindo enquanto navega pelas metas e desafios.

### 🎯 2. Metas Diárias Gentis (Gentle Habits)
- Sem cobranças tóxicas ou metas sobre-humanas.
- Micro-passos diários: beber água consciente, 3 minutos de respiração, 5 min de luz solar, desintoxicação de redes sociais.
- Opção para adicionar metas pessoais customizadas.
- Barra de progresso diária e celebração com confetes suaves ao concluir cada meta.

### 🏆 3. Desafios de Superação Gradual
- **Jornada de 7 Dias: Saindo da Tempestade** (Primeiros socorros para acalmar a mente).
- **Desafio 14 Dias: Reconstruindo a Autoestima** (Transformando a autocrítica em autocompaixão).
- Dias desbloqueáveis com tarefas práticas, afirmações diárias e integração direta com playbooks.

### 🚨 4. Botão SOS Ansiedade & Pânico (Acesso Imediato)
- **Respiração Guiada 4-7-8**: Círculo animado e instruções visuais que estimulam o nervo vago e desaceleram os batimentos cardíacos.
- **Técnica de Aterramento 5-4-3-2-1**: Interativa para reconectar os 5 sentidos e sair de crises agudas de despersonalização/pânico.
- **Apoio Imediato**: Link direto para ligar gratuitamente para o **CVV 188** (Centro de Valorização da Vida).

### 📖 5. Diário de Emoções & Vitórias
- Registro de humor em 5 estados emocionais com mensagens imediatas de acolhimento personalizado.
- Espaço seguro para desabafo sem julgamentos e anotação de micro-vitórias do dia.
- Histórico salvo localmente.

### 🎨 6. Design Moderno com Cantos Arredondados & Modo Escuro
- Interface com cantos ultra-arredondados (`rounded-3xl` e `rounded-4xl`), degradês terapêuticos e glassmorphism suave.
- Modo Escuro (Dark Mode) anti-fadiga ocular para uso noturno.
- Tela de login moderna com avatares emocionais ou modo visitante sem cadastro.

---

## 🚀 Como Executar Localmente

```bash
# Instalar as dependências
npm install

# Iniciar o servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```

Acesse em: `http://localhost:3000`
